# 🎨 Theme Development

The NIRM CMS uses the **Obii Theme Engine** for frontend rendering. The active theme is **`nirm`**, located at `platform/themes/nirm/`.

---

## Theme Structure

```
platform/themes/nirm/
├── assets/                     # Source assets (pre-compilation)
│   ├── js/                     # JavaScript source files
│   └── sass/                   # SASS stylesheets
│
├── config.php                  # Theme configuration
├── theme.json                  # Theme metadata
├── webpack.mix.js              # Asset compilation config
│
├── functions/                  # Theme functions (like WordPress functions.php)
│   ├── functions.php           # Main function file
│   ├── shortcodes.php          # Shortcode definitions
│   └── theme-options.php       # Theme option panel settings
│
├── helpers/
│   └── helpers.php             # Helper utility functions
│
├── lang/
│   └── en.json                 # English translations
│
├── layouts/                    # Page layout templates
│   ├── default.blade.php       # Default page layout
│   ├── homepage.blade.php      # Homepage layout
│   └── page_form.blade.php     # Form page layout
│
├── partials/                   # Reusable template parts
│   ├── header.blade.php        # Site header
│   ├── footer.blade.php        # Site footer
│   ├── top_bar.blade.php       # Top navigation bar
│   ├── menu_header.blade.php   # Header navigation menu
│   ├── footer-menu.blade.php   # Footer navigation menu
│   ├── breadcrumbs.blade.php   # Breadcrumb navigation
│   └── contact-form.blade.php  # Contact form partial
│
├── public/                     # Published public assets
│   ├── assets/                 # Compiled CSS/JS
│   └── screenshot.png          # Theme preview image
│
├── routes/
│   └── web.php                 # Theme-specific routes
│
├── screenshot.png              # Theme screenshot for admin
│
├── src/
│   └── Http/                   # Theme controllers
│
└── views/                      # Page templates
    ├── index.blade.php         # Homepage view
    ├── page.blade.php          # Static page view
    ├── post.blade.php          # Single blog post view
    ├── blogs.blade.php         # Blog listing page
    ├── category.blade.php      # Category archive
    ├── tag.blade.php           # Tag archive
    ├── search.blade.php        # Search results
    ├── resources.blade.php     # Resources page
    ├── loop.blade.php          # Post loop (used in listings)
    ├── 404.blade.php           # Not Found error page
    ├── 500.blade.php           # Server Error page
    ├── 503.blade.php           # Maintenance mode page
    ├── common/                 # Common view components
    ├── custom-fields/          # Custom field templates
    └── templates/              # Additional page templates
```

```json
    "author": "Nguyen Dac Huy",
    "version": "1.0",
    "required_plugins": ["form", "menu"]
}
```

## Layouts

Layouts define the overall page structure. Views extend layouts to add page-specific content.

### Available Layouts

| Layout | File | Usage |
|---|---|---|
| **Default** | `layouts/default.blade.php` | Standard pages with header/footer |
| **Homepage** | `layouts/homepage.blade.php` | Homepage with hero section |
| **Page Form** | `layouts/page_form.blade.php` | Pages with embedded forms |

### Using a Layout in a View

```blade
@extends(Theme::layout('default'))

@section('content')
    <h1>{{ $page->name }}</h1>
    {!! $page->content !!}
@endsection
```

---

## Partials

Include reusable components in layouts:

```blade
{{-- In a layout file --}}
{!! Theme::partial('header') !!}
{!! Theme::partial('breadcrumbs') !!}

@yield('content')

{!! Theme::partial('footer') !!}
```

## Theme Options

Theme options are defined in `functions/theme-options.php` and can be managed from **Admin → Appearance → Theme Options**.

Common options include:
- Logo image
- Favicon
- Social media URLs
- Footer text
- Color scheme
- Contact information

---

## Shortcodes

Custom shortcodes are defined in `functions/shortcodes.php`. Shortcodes let you embed dynamic content in pages:

```
[contact-form][/contact-form]
[slider key="homepage-slider"][/slider]
[blog limit="6"][/blog]
```

## Compiling Theme Assets

The theme has its own `webpack.mix.js` that is automatically included by the root `webpack.mix.js`:

```bash
# Compile all assets (theme + plugins)
npm run dev

# Watch for changes during development
npm run watch

# Build for production (minified)
npm run prod
```

---

## Creating a New Theme

```bash
php artisan cms:theme:create <theme-name>
```

Then set it as active in **Admin → Appearance → Theme**.

---

## Multi-Language Support

The theme supports three languages via the Language plugin:

| Language | Code |
|---|---|
| English | `en` |
| Hindi | `hi` |
| Kannada | `kn` |

Translation files are in `lang/en.json` and managed through the admin panel.
